# Assets

The active experiment uses procedural GratingStim stimuli configured in YAML and rendered by shared PsyFlow. No MP4 or PNG is used for active adaptation or static testing.

`motion/` retains a rejected movie strategy as reproducible feasibility evidence. The generated four-patch media have an offline actual-decode audit in `references/material_audit.json`; native movie synchronization failed and those files must not be described as validated task presentation. The generator is `scripts/generate_materials.py`. All generated stimulus material is original algorithmic material. Source articles are cited in references; no copyrighted article PDF is redistributed.
